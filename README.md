# 🃏 친구끼리 홀덤

로그인 없이 링크 하나로 친구들(최대 15명)과 같이 하는 텍사스 홀덤.

- 서버가 딜러 역할: 카드 섞기·나눠주기·베팅·타이머 모두 서버에서 처리 (남의 카드 엿보기 불가)
- 블라인드 200/400부터 6분마다 2배 자동 업 (최고 50,000/100,000) 또는 고정
- 차례당 15초, 리바인 선택, 칩 현황, 음성 안내, 컴퓨터 게스트 연습 게임

## 실행
```
npm install
npm start   # http://localhost:3000
```

## Render 배포
이 저장소를 Render의 **New → Blueprint** 로 연결하면 `render.yaml` 대로 무료 웹 서비스가 만들어져요.
